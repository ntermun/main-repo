nterminal pacman repository

Статические aarch64-linux-musl пакеты GNU userland. База: aarch64/nterminal.db.tar.gz, файлы: aarch64/nterminal.files.tar.gz.

pacman.conf

[options]
Architecture = aarch64
SigLevel = Never

[nterminal]
Server = https://ntermun.github.io/main-repo/aarch64

Установка

pacman -Sy
pacman -S bash coreutils grep sed gawk tar gzip findutils diffutils make openssl openssh

Пакеты не подписаны (SigLevel = Never), доверие — HTTPS и CI. Исходники сборки: ntermun/packages.
