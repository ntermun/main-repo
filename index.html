ntermun pacman repository

Статические aarch64-linux-musl пакеты для терминала ntermun. База: aarch64/ntermun.db.tar.gz, файлы: aarch64/ntermun.files.tar.gz.

pacman.conf

[options]
Architecture = aarch64
SigLevel = Never

[ntermun]
Server = https://ntermun.github.io/main-repo/aarch64

Установка

PREFIX=/data/data/nnn.ntermun/files
$PREFIX/usr/bin/pacman --root "$PREFIX" -Sy
$PREFIX/usr/bin/pacman --root "$PREFIX" -S pacman bash coreutils

Без pacman пакет можно распаковать напрямую:

tar --zstd -xf bash-5.3-1-aarch64.pkg.tar.zst -C /data/data/nnn.ntermun/files
